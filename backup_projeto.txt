CHANGELOG v1.1.0 - SISTEMA DE LOGIN E CADASTRO ADMINISTRATIVO
================================================================================

[LOGIN ADMINISTRATIVO]
- Tela de login (LoginDialog) exibida ao abrir o software com logo MADEMAXI.
- Autenticacao via AdminService.authenticate() usando PBKDF2 com salt.
- Senha mestra oculta: atalho F1 na tela de login abre prompt de senha mestra.
- Senha mestra validada via AdminService.validate_master_password().
- Senha mestra correta abre AdminRegisterDialog para cadastro de administradores.
- Sem senha mestra configurada, o primeiro acesso permite cadastro livre.

[TIPOS DE CONTA]
- Administrador (is_master=True): acesso total. Pode gerenciar usuarios,
  categorias de veiculos, alterar senha mestra e visualizar auditoria.
- Funcionario (is_master=False): acesso limitado. Pode registrar atividades,
  consultar historico, dashboard e gerar relatorios. Nao acessa a aba Gestao.
- Aba "Gestao" (admin_management_page) so aparece na sidebar se is_master=True.
- Titulo da janela exibe: "Dashboard Frotas — MADEMAXI | Logado: {nome_completo}".

[CADASTRO DE USUARIO]
- AdminRegisterDialog: campos nome_completo, username, senha (min 6 chars),
  checkbox "Administrador" (is_master).
- AdminEditDialog: edicao completa com nome_completo, username, nova senha
  (campo opcional), checkbox is_master, botao "Excluir Cadastro" vermelho.
- Botao "Alterar Cadastro" na AdminManagementPage abre o dialog de edicao.
- Impedimento de auto-exclusao/inativacao: mensagem "Nao e possivel excluir
  o perfil em uso" se o admin tentar excluir a propria conta.
- Soft delete: exclusao define is_active=False (nao remove do banco).
- Hard delete disponivel via AdminService.hard_delete_admin().

[SENHA MESTRA]
- Armazenada na tabela Setting com chave "master_password_hash".
- Hash gerado com PBKDF2 (sha256, 100000 iteracoes, salt de 16 bytes).
- Formato armazenado: "hash_hex:salt_hex".
- Alteracao via botao "Alterar Senha Mestra" na aba Gestao.
- Confirmacao com dupla digitacao da nova senha.

[MODELO DE DADOS]
- Admin model: id, username (unique), password_hash, nome_completo,
  is_master (bool), is_active (bool), created_at.
- database.py: importa app.models.admin no init_db() para criacao da tabela.
- AdminService: CRUD completo, autenticacao, validacao de senha mestra,
  hash/verify com secrets.compare_digest.

[REVAMP VISUAL DO LOGIN]
- Logo MADEMAXI reposicionado com scaled(220, 170, KeepAspectRatio).
- Texto "MADEMAXI" removido do login (ja presente no logo).
- Subtitulo "Dashboard de Controle de Frotas" abaixo do logo.
- Layout espacoso: dialog 420x520, logo container FixedHeight(200).
- Sem hint de cadastro visivel na tela (F1 e oculto).

[SEGURANCA]
- Nunca exibe senha antiga. Somente permite definir nova senha.
- Senhas armazenadas com hash + salt, nunca em texto plano.
- Comparacao de hash via secrets.compare_digest (timing-safe).

[NOME/IDENTIFICACAO DO VEICULO]

[MEMORIA PERSISTENTE EM REGISTRAR ATIVIDADE]
- Ao salvar uma atividade, o sistema NAO limpa mais o veiculo selecionado nem
  a data. Apenas quantidade volta para 1 e observacoes sao limpas.
- Isso permite registrar multiplas atividades para o mesmo veiculo/data sem
  precisar reselecionar a cada vez.
- refresh_vehicles() em ActivityRegisterPage e HistoryPage preserva a
  selecao atual ao recarregar a lista.

[HISTORICO - COMBO VEICULO SOMENTE LEITURA]
- cb_vehicle.setEditable(False) no HistoryPage. Nao e mais possivel digitar,
  apenas selecionar um veiculo do dropdown.

================================================================================
SCHEMA DO BANCO DE DADOS
================================================================================

Tabela veiculos:
  id INTEGER PK
  placa VARCHAR(10) UNIQUE
  modelo VARCHAR(80)  -- usado como "Nome / Identificacao"
  marca VARCHAR(80)
  ano INTEGER
  categoria VARCHAR(20)
  status VARCHAR(20)
  observacoes TEXT
  created_at DATETIME

Tabela atividades:
  id INTEGER PK
  veiculo_id INTEGER FK -> veiculos.id
  data_hora DATETIME
  quantidade INTEGER
  observacoes TEXT
  created_at DATETIME

Tabela admins:
  id INTEGER PK
  username VARCHAR(50) UNIQUE
  password_hash VARCHAR(128)
  nome_completo VARCHAR(100)
  is_master INTEGER DEFAULT 0
  is_active INTEGER DEFAULT 1
  created_at DATETIME

Tabela configuracoes:
  id INTEGER PK
  chave VARCHAR(50) UNIQUE
  valor TEXT

Tabela auditoria:
  id INTEGER PK
  usuario VARCHAR(100)
  acao VARCHAR(20)
  entidade VARCHAR(50)
  entidade_id INTEGER
  descricao TEXT
  data_hora DATETIME DEFAULT now
  data_retroativa DATETIME
